# Database SQL

Bu klasördeki `04_create_synthetic_gas_yenimahalle.sql` dosyası Ankara/Yenimahalle için tamamen sentetik doğalgaz demo verisi üretir.

- Veri gerçek doğalgaz altyapısını temsil etmez.
- Veri eğitim, demo ve yazılım geliştirme/test amacıyla hazırlanmıştır.
- SRID `EPSG:3857` olarak kullanılır.
- Demo ağ yaklaşık Yenimahalle/Ankara çalışma alanındadır.
- Mevcut `cbs.vanalar` ve `cbs.borular` tablolarını değiştirmez.
